## Install or update

In the ComfyUI editor, use **top-left dropdown > Extensions > Nodes Manager > search `byteplus`**. Choose **ComfyUI BytePlus ModelArk, Speech, OmniHuman & MediaKit** from **byteplus-sa**, then **Install** or **Update** for an existing installation. Wait for completion, then **Apply Changes** if prompted or restart ComfyUI.

Use **Nodes Manager first**, **Comfy CLI second**, and a **release ZIP only as a last resort**. Follow the illustrated [installation guide](./get-started/install/) or [update guide](./get-started/update/). New to ComfyUI? Start with [Module 1 of the course](./tutorials/install-comfyui/).

## Generate audio with ModelArk

[Seed Audio 1.5](./nodes/seed-audio-1-5/) creates full-scene audio, uses reference voices or an image, generates video-guided audio, translates video and separates stems. Use your ModelArk key in Singapore; the existing Seed Audio 1.0 node remains on Seed Speech.

## Create a talking avatar

[Avatar Generation](./templates/avatar-generation/) connects Seedream 5.5, Seed Audio and OmniHuman in one native workflow. Generate a portrait and narration or supply your own, then save the talking avatar video. The guide also explains how to run selected outputs to review the portrait and voice before starting video generation.

Prefer a form instead of the node canvas? Open [Custom Apps](./custom-apps/) and
follow the [Avatar Studio installation guide](./custom-apps/avatar-studio/).
Studio is a separate browser app with explicit portrait and narration approvals.
