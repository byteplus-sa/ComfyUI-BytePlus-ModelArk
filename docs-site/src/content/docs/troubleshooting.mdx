Errors appear in the node with a `[BytePlus]` prefix. The tables quote the text after it, shortened where a message has placeholders. Node pages list errors that belong to one node.

## Keys and setup

| What you see | Why | What to do |
|---|---|---|
| `No BytePlus API key is set. Add it in Settings > BytePlus` | No ModelArk key is saved. | Save it in **Settings → BytePlus**. See [API keys](../get-started/api-keys/). |
| `No Seed Speech API key is set.` or `No AI MediaKit API key is set.` | These nodes use their own keys. | Save that key in **Settings → BytePlus**. |
| `Invalid API Key (401). Check the key in Settings > BytePlus, and that the region there matches the region the key was created in.` | Wrong key, or the region does not match it. | Pick the key's region and save again. See [Keys and regions](../concepts/keys-and-regions/). |
| `ModelArk API keys do not work with Seed Speech.` | A ModelArk key was used for speech. | Create a Seed Speech key and activate the service in its console. |
| `Your account … has not activated the model …` | The model is not activated for this region. | Activate it in the ModelArk console (**Model activation**). |
| `{model} is not available in {region}.` | For example Seedream 5.0 Lite in `eu-west-1`. | Pick another model or region. See [Models](../models/). |
| `Account Overdue (403)` | Your BytePlus balance is unpaid. | Top up in the BytePlus billing center. |

## Content filter

| What you see | Why | What to do |
|---|---|---|
| `Generated image contains sensitive content (400). This filter sometimes rejects harmless content: run again with another seed, or rephrase the prompt.` | The output filter sometimes rejects harmless results, also for video and audio. | Run again with another `seed`, or rephrase. |
| `Input image contains sensitive content (400).` | The filter rejected media you connected. | Use other media. Text, video and audio work the same way. |
| `Request failed: input image or video may contain a real person.` | Seedance blocks reference media with a real person. | Use another image, or a verified asset. |
| `Generated video may be restricted due to copyright policy (400).` | The result looked like protected material. | Change the prompt. |

## Rate limits and quota

| What you see | Why | What to do |
|---|---|---|
| `Rate Limit Exceeded (429). Please try again later.` | Too many requests at once. | Wait, or lower `generation_count`. |
| `Endpoint RPM limit exceeded (429)` or `Endpoint TPM limit exceeded (429)` | Requests or tokens per minute are used up. | Wait a minute. |
| `Account … has exhausted the free trial quota for model …` | The free quota is used up. | Activate the model service in the ModelArk console. |
| `Account … has reached the set inference limit for model …` | A limit on your account is reached. | Adjust the limit, or disable Safe Experience Mode on the Model activation page. |
| `Seed Speech concurrency limit reached.` | Too many speech requests at once. | Wait for running requests to finish. |

Paid requests are not repeated after a failure, because a repeat could bill twice.

## Video tasks

| What you see | Why | What to do |
|---|---|---|
| `Task is currently running and cannot be cancelled (409). It keeps running and will be billed; only queued tasks can be cancelled.` | You interrupted a running task. | Find it later with **Video Query Tasks**. |
| `Waiting for … min already.` | Seedance 2.5 Premium (4K) tasks can stay queued or running for tens of minutes. | Keep waiting. A running task is billed even if you interrupt. |
| `No task found for …` | The ID is unknown. ModelArk keeps tasks for 7 days. | Copy the Task ID from the console, or the `draft_task_id` of a draft run. |
| `With a reference video connected, set task_type to reference, edit or extend instead of auto.` | `auto` with a reference video can be rejected. | Set `task_type` to `reference`, `edit` or `extend`. |
| `Task … is not a draft.` | The ID is not from a Draft model. | Use the `draft_task_id` of a Seedance 2.5 Draft run. |

## Speech

| What you see | Why | What to do |
|---|---|---|
| `The voice is not available for this key or model.` | The speaker does not fit the model. | TTS 2.0 voices need `seed-tts-2.0`, cloned voices `seed-icl-*`. |
| A Seed Audio link has no file extension | The API returns it that way. | Nothing: Seed Speech ASR detects the format. |
| `… takes audio as a URL: connected audio is uploaded to Comfy.org storage first.` | Standard ASR models only take URLs. | Log in to Comfy.org, use `seed-asr-fast`, or pass a public URL. |

## Assets and Comfy.org login

Local videos go through Comfy.org storage, because BytePlus only takes links for them. Log in to Comfy.org in ComfyUI and do not start it with `--disable-api-nodes`.

| What you see | Why | What to do |
|---|---|---|
| `Uploading the reference video to Comfy.org storage failed … Log in to your Comfy.org account in ComfyUI` | You are not logged in. | Log in, or use a public mp4 or mov link or an asset ID in an `asset_N` input. |
| `The asset library needs IAM AK/SK with asset-library permission` | The IAM keys are not saved. | Save them in **Settings → BytePlus**. |
| `CreateAsset is rate-limited by your Advanced Creation Rights tier` | Too many asset requests per minute. | Wait and run again. |

## ComfyUI quirks

- **Changing a key does not rerun the workflow.** ComfyUI caches results by input values, so an unchanged workflow reuses its earlier result. Change a prompt or seed.
- **A node did not run.** Nodes run only when something uses their output. Connect **Save Image** or **Save Video**.
- **A saved key is ignored.** An environment variable with the same name wins over `user/.env`. Settings tells you when that happens.
