Start with **top-left dropdown > Extensions > Nodes Manager > search `byteplus` > Update**. Use [Nodes Manager first](#update-with-nodes-manager-recommended), the [Comfy CLI second](#update-with-the-comfy-cli), and a [release ZIP only as a last resort](#update-a-manual-zip-last-resort). The [Comfy Registry](https://registry.comfy.org/nodes/ComfyUI-BytePlus-ModelArk) lists package versions. Your saved keys stay in `user/.env`, outside the pack folder.

Version **0.8.0** adds [Seedream 5.5](../../nodes/seedream/) and its [layer-separation options](../../nodes/seedream-layer-separation/). After updating, select `seedream 5.5` on either node; existing workflows keep their previous model. Your account needs early-access entitlement. Media URLs must resolve to public addresses; local and private-network download URLs are rejected.

Registry publication and security review are separate steps. A pending or flagged version may not be offered by Manager yet; check its version status rather than enabling unsafe installation overrides.

## Seedream 5.5 4K UHD

Version **0.15.0** adds fixed UHD presets to [Seedream 5.5](../../nodes/seedream/). Registry installation availability depends on the version's scan status.

- After updating, restart ComfyUI and reload the browser. Select `seedream 5.5`, then choose `(4K) 3840x2160 (16:9)` or `(4K) 2160x3840 (9:16)` in `size_preset`.
- Custom sizes allow up to 8,294,400 pixels, with aspect ratios from 1:16 to 16:1. The fixed presets send explicit dimensions, not an adaptive `4K` API value.
- Existing workflows retain their previous selections. The 2K-adaptive default, model ID, saved keys, other image models and layer-separation limits are unchanged.

## Seed Audio 1.5

Version **0.13.0** adds [Seed Audio 1.5](../../nodes/seed-audio-1-5/) for audio generation, voice or image references, video-guided audio, video translation and stem separation.

- Restart ComfyUI, reload the browser and add **BytePlus Seed Audio 1.5**. Use your **ModelArk API key** and select Singapore in **Settings > BytePlus**.
- Seed Audio 1.0 remains a separate Seed Speech node. Existing workflows and saved keys do not need migration.
- Every returned track is available through the list outputs. Enable the advanced video and subtitle options when needed, then connect **Save Audio** or **Save Video** to keep results.
- Connected videos require Comfy.org storage. Their exact encoded size is checked before upload, including trimmed and cropped sources.
- Pending cancellation prevents a new submission. Once accepted, remote work may continue and be billed after local cancellation. Submissions are never retried automatically.

## Seed TTS 3 and Seedream controls

Version **0.12.0** adds the separate [Seed Speech TTS 3](../../nodes/seed-tts-3/) node with 520 preset voices, delivery instructions, optional word timings and conversation sessions. Use your existing Seed Speech API key. Older TTS nodes and workflows are unchanged.

- Pick a voice from the dropdown, or paste an authorized preset or compatible cloned voice ID into `custom_speaker_id` to override it.
- Select the output language separately. Subtitles depend on language support; cloned voices must be compatible with TTS 3.
- Seedream 5.5 fixed-size presets and shared controls now follow current ComfyUI core. The initial model stays 5.0 Pro; 5.5 keeps its 2K-adaptive, PNG and automatic-background defaults.
- New 5.5 layer-separation nodes default to `minimal size`; Pro and Flash retain `full canvas`. Check older saved 5.5 workflows after reloading, especially fixed-size preset selections and widget values, before submitting billed work.

## Seedance draft to 4K

Version **0.12.0** adds `1080p` and `4k` choices to [Seedance 2.5 Draft to Final Video](../../nodes/seedance-2-5-draft-to-final/). Existing workflows keep the 1080p default.

- Restart ComfyUI and reload the browser after updating. Keep the draft node on **Seedance 2.5 Draft** at 480p, with a fixed seed.
- Select `4k` on the final node to render the reviewed draft at 4K. Draft and final are separate billed tasks.
- Keep the Seedance 2.5 endpoint override in Settings unchanged between draft and final. For pasted IDs, restore the endpoint that created the draft, or leave it empty if the draft used the model directly.
- No new key, model ID or automatic paid retry is introduced. Draft IDs remain valid for seven days.

## OmniHuman avatar generation

Version **0.10.0** adds [OmniHuman 2.0](../../nodes/omnihuman/) image-plus-audio avatar generation, [Task Result](../../nodes/omnihuman-task-result/) collection and explicit [Cancel Task](../../nodes/omnihuman-cancel-task/) for queued work.

- Save a separate Vision AI key in **Settings > BytePlus > OmniHuman Vision AI API key**. ModelArk, Speech and MediaKit keys are not substitutes.
- Connect one portrait and speech audio, or use public media URLs. Audio can last **4-300 seconds**, including five minutes. Oversized connected WAVs are downmixed to mono and resampled to at most 24 kHz without truncation.
- Connect **Save Video** to keep the result. Accepted tasks can resume from private recovery records without another paid submission.
- Interrupting local execution does not cancel remote processing or billing. Cancellation is explicit and works only while the task is queued.

## Credential and reference-link hardening

Version **0.9.1** hardens key validation and reference links without changing node IDs or model choices. Your saved keys stay in `user/.env`.

- ModelArk key validation contacts only the fixed regional BytePlus HTTPS endpoint, uses public-only networking and does not follow redirects. A redirect leaves the key unchecked instead of accepting it.
- Malformed API keys are rejected before validation. Validation-error logs do not include credential text.
- Shared HTTP requests carrying API credentials are restricted to the corresponding BytePlus HTTPS services.
- Reference links must use public HTTPS URLs without embedded usernames or passwords. Private addresses and malformed destinations are rejected, including probe redirects. Use a public media link or a connected media input instead.

## Seedance 2.5 4K and Flash

Version **0.9.0** adds unified Seedance 2.5 4K and Seedance 2.5 Flash support. These changes are not included in v0.8.0.

After updating to v0.9.0:

- For direct 4K generation, select **Seedance 2.5** and set `resolution` to `4k`. It uses the same model as 480p, 720p and 1080p.
- **Seedance 2.5 Premium** and **Premium Draft** are removed without aliases or automatic migration. Replace a Premium selection with **Seedance 2.5** and `4k`. If you used Premium Draft, generate a new **Seedance 2.5 Draft** for a 1080p final, or use direct 4K generation instead. Old Premium drafts cannot be converted by this update.
- Select **Seedance 2.5 Flash** in the same [Text to Video](../../nodes/seedance-2-5-text-to-video/), [First-Last-Frame](../../nodes/seedance-2-5-first-last-frame/) or [Reference to Video](../../nodes/seedance-2-5-reference/) node. Flash supports 480p/720p and 4-30 seconds, uses the API's default output format and has no Draft option. Your account needs private-model access and activation.
- The standard Seedance 2.5 endpoint applies at every standard resolution, including 4K. It does not override Flash. Your saved keys stay unchanged.

## Update with Nodes Manager (recommended)

<Steps>

1. Open the ComfyUI editor's **top-left dropdown**, then choose **Extensions** to open **Nodes Manager**.
2. Search for **byteplus** and select **ComfyUI BytePlus ModelArk, Speech, OmniHuman & MediaKit** from **byteplus-sa**. You can also check **Updates Available** in the sidebar.
3. Open the installed package's card and choose **Update**. Use the adjacent dropdown to review the available update options if needed.
4. Wait for the update to finish, then click **Apply Changes** if prompted, or restart ComfyUI. Reload the editor after the restart.

</Steps>

<Shot src="guides/nodes-manager-update.webp" alt="Installed BytePlus ModelArk package in Nodes Manager with Update in its details panel" caption="Open the installed package's card to find Update and its option dropdown." />

The **OmniHuman nodes** update with ModelArk. If you use the separate **BytePlus Avatar Studio** app, update both `ComfyUI-BytePlus-ModelArk` and `ComfyUI-BytePlus-Avatar-Studio` through the same search results.

<Aside type="note" title="No release is available for the selected update option">
This message is not proof that you have the newest version. Check the update dropdown and compare your installed version with the Registry's versions. You may already have the selected release, or no eligible release may be available for that option. A listing marked Active does not guarantee that each version is approved; pending or flagged versions may be unavailable. The CLI uses the same Registry.
</Aside>

If Manager shows **Install** for a folder that already exists, follow [If the install path already exists](../install/#if-the-install-path-already-exists). Do not keep retrying Install over the same folder.

## Update with the Comfy CLI

Use this second option with the CLI configured for the **same ComfyUI installation you open**:

```bash
comfy node update ComfyUI-BytePlus-ModelArk
```

To see what is installed, run `comfy node show installed`. Restart ComfyUI and reload the browser page afterwards. To update ComfyUI itself, use `comfy update`.

If you use Avatar Studio, also run `comfy node update ComfyUI-BytePlus-Avatar-Studio`.

## Update a manual ZIP (last resort)

Prefer switching to Nodes Manager using the [existing-folder recovery steps](../install/#if-the-install-path-already-exists). If you must stay with ZIP installation:

<Steps>

1. Download the required release ZIP from [GitHub Releases](https://github.com/byteplus-sa/ComfyUI-BytePlus-ModelArk/releases), then close ComfyUI.
2. Move the old pack folder to a backup **outside `custom_nodes`**. Extract the new version into `custom_nodes/ComfyUI-BytePlus-ModelArk/`, without nesting another pack folder inside it.
3. From your ComfyUI folder, install requirements with **the same Python that runs ComfyUI**:

   ```bash
   python -m pip install -r custom_nodes/ComfyUI-BytePlus-ModelArk/requirements.txt
   ```

4. Restart ComfyUI and reload the editor. Leave `user/`, workflows and `user/.env` untouched.

</Steps>

For an existing developer Git checkout, continue using `git pull` and install its requirements with ComfyUI's Python. A ZIP extraction is not a Git checkout and cannot be updated with `git pull`.

<Aside type="note">
If the BytePlus nodes do not appear after an update, the BytePlus SDK may be too old. ComfyUI prints the exact `pip install` command in its console. See [If the BytePlus SDK is missing](../install/#if-the-byteplus-sdk-is-missing).
</Aside>

## After updating

- Reload the browser page, not only the server, so the new Settings page and node definitions load.
- Node IDs do not change, but a removed model choice must be replaced manually as described above. Saved workflows keep their own node settings; open a template again from the template browser to get the newest one.
- Before reporting a problem, check the installed version in Nodes Manager and compare it with the available versions on the Registry page.

## Media input layout

Version **0.14.0** moves media sockets out of mode/model groups on Seed Audio 1.0 and 1.5,
Seedream, Layer Separation, Seedance Reference and BytePlus LLM. Media connects on the left;
outputs remain on the right. Restart ComfyUI and reload the browser after updating.
Registry availability depends on the version's scan status.

Saved canvas workflows are upgraded when opened: existing media links are renamed without
changing prompt or widget values. Save the workflow again after checking its connections.
Models and modes still enforce their own media limits. Disconnect media that the selected
mode or model does not support; conflicting sources are rejected rather than silently replaced.

For API-format workflows submitted directly without opening the canvas, update media keys yourself:
`mode.video` becomes `video`, `reference_mode.reference_audio_1` becomes `reference_audio_1`,
`model.image` becomes `image`, and `model.images.image_1` becomes `images.image_1`.
The same rule applies to video/audio Autogrow groups, Seedream's `reference_mask`, and
Seedance's `reference_images`, `reference_videos` and `reference_audios`.
Leave prompt, URL, asset and other mode/model control keys unchanged.
