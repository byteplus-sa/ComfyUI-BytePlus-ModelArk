Templates are ready-made workflows. The quickest way to test your setup is the **Seedream** template: it needs only a ModelArk API key and makes one image.

## Before you start

- The pack is installed ([Install](../install/)).
- Your ModelArk API key is saved in **Settings → BytePlus** ([API keys](../api-keys/)).
- The Seedream model is activated in the ModelArk console for the region of your key.

## Run the template

<Steps>

1. Open the **Templates** browser in ComfyUI.
2. Choose the BytePlus templates and pick **Seedream**.
3. Press **Run**.
4. Wait for the Seedream node to finish. The picture appears in **Save Image**.

</Steps>

The steps and the settings worth changing are on the [Seedream template page](../../templates/seedream/).

## Save Image and Save Video

The BytePlus generation nodes save nothing themselves. They only run when another node uses their output. That is why most templates end in a **Save** node such as **Save Image** or **Save Video**; a few only show the result in a preview node. If you build your own workflow, connect a Save node to keep the result, or a preview node to look at it. A BytePlus node with nothing connected to its output does not run and is not billed. The exceptions are the lookup nodes **Video Query Tasks** and **Asset Library**, which run on their own.

## What a run costs

A run sends your prompt to BytePlus and **bills your own BytePlus account**. No Comfy credits are used. The Seedream template bills for one image. ComfyUI reuses the cached result of a node whose inputs did not change, but this template sets the `seed` control to `randomize`, so each new run changes the seed and bills one more image. Set the control to `fixed` to get the cached result back. More in [Billing and cost](../../concepts/billing-and-cost/).

## Where results are saved

**Save Image** and **Save Video** write to the `output` folder inside your ComfyUI folder, like any other ComfyUI output. Preview nodes show the result but do not keep it.

## If the key is missing

Without a key the node stops before it sends anything and the run fails with this message:

> No BytePlus API key is set. Add it in Settings > BytePlus, or put BYTEPLUS_API_KEY=... in … (or set the BYTEPLUS_API_KEY environment variable).

Save the key, then run again. You do not need to restart ComfyUI. The Seed Speech and AI MediaKit nodes give the same kind of message for their own keys. In the real message, the “…” is the path of your `.env` file.

<Aside type="tip">
Other common first errors: *Invalid API Key (401)* means the key and region do not match. *has not activated the model* means you must activate the model in the ModelArk console for that region.
</Aside>
