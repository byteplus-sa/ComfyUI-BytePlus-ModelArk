The nodes call BytePlus with **your own keys**. You save each key once in **Settings → BytePlus**. Workflows contain no keys and no client nodes, so you can share a workflow safely.

## The four key types

Each BytePlus product has its own key. They are not interchangeable: a ModelArk API key does not work on a Seed Speech node.

| Key | Create it in | Used by |
|---|---|---|
| ModelArk API key | [ModelArk console](https://ai.byteplus.com/ark/region:ap-southeast-1/apikey) | Seedream, Seedance, Video Query Tasks, BytePlus LLM and the asset library nodes |
| Seed Speech API key | [Seed Speech console](https://console.byteplus.com/voice/new/overview?projectName=default), then Settings → API Keys. Activate the services first. | Seed Audio, Seed Speech TTS, ASR and Voice Clone |
| AI MediaKit API key | [AI MediaKit console](https://console.byteplus.com/vodpaas/region:vodpaas+ap-southeast-1/ai-mediakit/settings?tab=apiKey), then Settings → API key | vCube Video Enhance, Video Smoothness Enhance, Image Quality Enhance |
| IAM access key and secret key | IAM console. Use a sub-user whose policy allows only the asset library. | Create Image, Video and Audio Asset, Asset Library, and looking up an asset ID in an `asset_N` input |

You only need the keys for the nodes you use. Each node page lists them in its **Keys needed** row.

## Save a key in Settings

<Steps>

1. Open **Settings** (the gear icon, or Ctrl+, / Cmd+,) and search for **BytePlus**.
2. Under **Default credentials**, find the row for your key, for example **ModelArk API key**.
3. Paste the key. For the ModelArk API key, also pick its region.
4. Press **Save**. **Remove** deletes the saved value again.

</Steps>

<Shot src="guides/settings-byteplus-not-set.jpg" alt="Settings, BytePlus page: three default endpoint rows using built-in models and four empty credential rows, including ModelArk with a region drop-down" caption="Before saving: keys are not set and optional endpoints use the built-in models." />

ModelArk API keys are checked with BytePlus before they are saved. A wrong key is refused and nothing is written. If BytePlus cannot be reached, the key is saved and Settings says it could not be checked. The key takes effect at once, with no restart. Seed Speech and AI MediaKit API keys are saved without a check.

<Shot src="guides/settings-byteplus-key-set.jpg" alt="Settings, BytePlus page: ModelArk key set with the sample suffix abcd; other credentials are not set and three default endpoint rows use built-in models" caption="After saving: the row shows only the last four characters (here the sample value abcd) and where the key is stored." />

Keys are never shown again. Settings only says whether a key is set, where it comes from and its last four characters. The key is written to `user/.env` in your ComfyUI folder and never into a workflow file.

The IAM access key and secret key go together: fill in both. Settings has no field for an STS session token. To use one, add `BYTEPLUS_SESSION_TOKEN` to `user/.env` after you save the pair, because saving or removing the pair in Settings also removes that line.

## Default model endpoints

In **Settings → Other → BytePlus → Default credentials**, you can also set **Seedance 2.0 default endpoint**, **Seedance 2.5 default endpoint** and **Seedream 5.0 Pro default endpoint**. Enter a ModelArk endpoint ID (`ep-...`), not a URL. You still select the model on the node; the endpoint uses your saved ModelArk API key and region.

Each endpoint must serve exactly the named model in your key's region. Saving checks the ID format only, without generating media or checking model access. Leave the field blank and press **Save**, or press **Remove**, to return to the built-in model. Environment variables still take precedence.

The Seedance 2.5 endpoint also applies to **Seedance 2.5 Draft**. The Seedream Pro endpoint also applies to **Layer Separation** with Pro selected. Fast, Mini, Premium, Flash and other model variants keep their own built-in IDs.

Changes take effect without restarting and invalidate cached outputs for the selected model on the next run. A pending non-blocking task keeps running when you change endpoints; find it with **Video Query Tasks** and `model` set to `all`. **Draft to Final** keeps the model or endpoint recorded on its draft. If the draft reports an endpoint ID, keep it configured until you render the final.

## Or edit `user/.env` by hand

Create `user/.env` in your ComfyUI folder and add only the lines you need. Use your own values in place of the placeholders:

```
BYTEPLUS_API_KEY=your-modelark-key
BYTEPLUS_REGION=ap-southeast-1
BYTEPLUS_SEED_SPEECH_API_KEY=your-seed-speech-key
BYTEPLUS_VOD_MEDIAKIT_API_KEY=your-mediakit-key
BYTEPLUS_ACCESS_KEY=your-iam-access-key
BYTEPLUS_SECRET_KEY=your-iam-secret-key
```

For optional endpoints, set `BYTEPLUS_SEEDANCE_2_0_ENDPOINT`, `BYTEPLUS_SEEDANCE_2_5_ENDPOINT` or `BYTEPLUS_SEEDREAM_5_0_PRO_ENDPOINT` to the matching `ep-...` ID. Leave unused variables unset.

The file is read again whenever it changes, so no restart is needed. The pack never touches other lines in it. **Settings → BytePlus** shows its path under the ModelArk row ("Saved in …"). The file does not exist until you save a key or endpoint.

## Region

Pick the region where you created the ModelArk API key: `ap-southeast-1` (the default) or `eu-west-1`. A key and a region that do not match give an *Invalid API Key (401)* error. Settings catches this when you save: it says BytePlus rejected the key for the selected region. See [Keys and regions](../../concepts/keys-and-regions/).

## Environment variables win

A real environment variable with the same name beats the value in `user/.env`. Settings tells you when that happens ("An environment variable overrides the value in user/.env"). If `BYTEPLUS_REGION` is set as an environment variable, the region drop-down is locked, because the variable decides.

## Keep your keys safe

<Aside type="caution">
ComfyUI has no login. Anyone who can open your ComfyUI page, for example with `--listen` on a shared network, can use your keys and replace them in Settings. Do not expose ComfyUI to networks you do not trust. Never commit `user/.env`.
</Aside>

## Check that it works

Add **BytePlus LLM**, type `Reply with OK`, choose **Seed 2.0 Mini** and connect the output to **Preview as Text** (**Preview Any** in older ComfyUI). Press **Run**. It costs a few tokens. Change the prompt or seed between runs, because ComfyUI reuses the cached result of an unchanged node.
