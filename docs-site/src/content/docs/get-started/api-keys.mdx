The nodes call BytePlus with **your own keys**. You save each key once in **Settings → BytePlus**. Workflows contain no keys and no client nodes, so you can share a workflow safely.

## The four key types

Each BytePlus product has its own key. They are not interchangeable: a ModelArk key does not work on a Seed Speech node.

| Key | Create it in | Used by |
|---|---|---|
| ModelArk API key | [ModelArk console](https://ai.byteplus.com/ark/region:ap-southeast-1/apikey) | Seedream, Seedance, BytePlus LLM and the asset library nodes |
| Seed Speech API key | [Seed Speech console](https://console.byteplus.com/voice/new/overview?projectName=default), then Settings → API Keys. Activate the services first. | Seed Audio, Seed Speech TTS, ASR and Voice Clone |
| AI MediaKit API key | [AI MediaKit console](https://console.byteplus.com/vodpaas/region:vodpaas+ap-southeast-1/ai-mediakit/settings?tab=apiKey), then Settings → API key | vCube Video Enhance, Video Smoothness Enhance, Image Quality Enhance |
| IAM access key and secret key | IAM console. Use a sub-user whose policy allows only the asset library. | Create Image, Video and Audio Asset, and Asset Library |

You only need the keys for the nodes you use. Each node page lists them in its **Keys needed** row.

## Save a key in Settings

<Steps>

1. Open **Settings** (the gear icon, or Ctrl+, / Cmd+,) and search for **BytePlus**.
2. Find the row for your key, for example **ModelArk API key**.
3. Paste the key. For the ModelArk key, also pick its region.
4. Press **Save**.

</Steps>

<Shot src="guides/settings-byteplus-not-set.jpg" alt="Settings, BytePlus page with the ModelArk API key row empty and the status line saying not set" caption="Before saving: the row says the key is not set." />

ModelArk keys are checked with BytePlus before they are saved. A wrong key is refused and nothing is written. The key takes effect at once, with no restart.

<Shot src="guides/settings-byteplus-key-set.jpg" alt="Settings, BytePlus page after saving: the status line says the ModelArk API key is set and shows its last four characters" caption="After saving: only the last four characters are shown." />

Keys are never shown again. Settings only says whether a key is set, where it comes from and its last four characters. The key is written to `user/.env` in your ComfyUI folder and never into a workflow file.

The IAM access key and secret key go together: fill in both. To use an STS session token, set `BYTEPLUS_SESSION_TOKEN` in `user/.env`.

## Option B: edit `user/.env`

Create `user/.env` in your ComfyUI folder and add only the lines you need. Use your own values in place of the placeholders:

```
BYTEPLUS_API_KEY=your-modelark-key
BYTEPLUS_REGION=ap-southeast-1
BYTEPLUS_SEED_SPEECH_API_KEY=your-seed-speech-key
BYTEPLUS_VOD_MEDIAKIT_API_KEY=your-mediakit-key
BYTEPLUS_ACCESS_KEY=your-iam-access-key
BYTEPLUS_SECRET_KEY=your-iam-secret-key
```

The file is read on every run, so no restart is needed. The pack never touches other lines in it. **Settings → BytePlus** shows its path under the ModelArk row.

## Region

Pick the region where you created the ModelArk key: `ap-southeast-1` (the default) or `eu-west-1`. A key and a region that do not match give an *Invalid API Key (401)* error. See [Keys and regions](../../concepts/keys-and-regions/).

## Environment variables win

A real environment variable with the same name beats the value in `user/.env`. Settings tells you when that happens ("An environment variable overrides the value in user/.env"). If `BYTEPLUS_REGION` is set as an environment variable, the region drop-down is locked, because the variable decides.

## Keep your keys safe

<Aside type="caution">
ComfyUI has no login. Anyone who can open your ComfyUI page, for example with `--listen` on a shared network, can use your keys and replace them in Settings. Do not expose ComfyUI to networks you do not trust. Never commit `user/.env`.
</Aside>

## Check that it works

Add **BytePlus LLM**, type `Reply with OK`, choose **Seed 2.0 Mini** and connect the output to **Preview as Text**. Press **Run**. It costs a few tokens. Change the prompt or seed between test runs, because ComfyUI reuses the cached result of an unchanged node.
