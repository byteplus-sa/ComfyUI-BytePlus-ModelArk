A node is one block on the ComfyUI canvas. Each node here calls a BytePlus service directly and bills your own BytePlus account, with a key you save once in **Settings → BytePlus** (see [API keys](../get-started/api-keys/)). Nodes only run when something uses their output, such as **Save Image** or **Save Video**, and a node with nothing connected is not run and not billed.

All 22 nodes are listed below. Open a node's page for its inputs, outputs, limits and common errors.

## Images

| Node | What it does | Key |
|---|---|---|
| [Seedream 4.5 & 5.0](./seedream/) | Creates or edits images from a text prompt and optional reference images, up to 4K. | ModelArk |
| [Seedream 5.0 Layer Separation](./seedream-layer-separation/) | Splits one image into a background plate and up to 16 transparent layers, each with a name and position. | ModelArk |

## Video: Seedance 2.5

These nodes offer Seedance 2.5, 2.5 Premium and the 2.0 models in one `model` choice.

| Node | What it does | Key |
|---|---|---|
| [Seedance 2.5 Text to Video](./seedance-2-5-text-to-video/) | Makes a video from a text prompt. | ModelArk |
| [Seedance 2.5 First-Last-Frame to Video](./seedance-2-5-first-last-frame/) | Makes a video from a first frame image and an optional last frame image. | ModelArk |
| [Seedance 2.5 Reference to Video](./seedance-2-5-reference/) | Generates, edits or extends a video from reference images, videos and audio. | ModelArk |
| [Seedance 2.5 Draft to Final Video](./seedance-2-5-draft-to-final/) | Renders the full-quality video of a draft you made earlier, keeping its scene and motion. | ModelArk |

## Assets

The asset nodes need Advanced Creation Rights on your BytePlus account.

| Node | What it does | Key |
|---|---|---|
| [Create Image Asset](./create-image-asset/) | Adds an image to your private asset library and outputs its asset ID. | ModelArk, IAM access key and secret key |
| [Create Video Asset](./create-video-asset/) | Adds a video to your private asset library and outputs its asset ID. | ModelArk, IAM access key and secret key |
| [Create Audio Asset](./create-audio-asset/) | Adds an audio clip (WAV or MP3, 2 to 30 seconds) to your private asset library. | ModelArk, IAM access key and secret key |
| [Asset Library](./asset-library/) | Lists the assets in your private library as `asset://` links for Seedance references. | ModelArk, IAM access key and secret key |
