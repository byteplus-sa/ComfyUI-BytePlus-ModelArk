## What it does

Registers an audio clip (WAV or MP3, 2 to 30 seconds, up to 15 MB) in your private asset library and outputs its `asset_id`, `group_id` and an `asset://` URI, so a Seedance 2 or 2.5 reference can use the asset instead of the clip. It needs Dreamina Seedance Advanced Creation Rights, the ModelArk API key, and the IAM access key and secret key saved in **Settings → BytePlus** (see [API keys](../../get-started/api-keys/)). It generates nothing, and you should only use audio you are authorized to use.

## Inputs

<NodeInputs id="BytePlusCreateAudioAsset" />

### Notes on inputs

- **Audio source:** connect `audio`, or set `audio_url` to a public HTTPS link to a .wav or .mp3 file, not both. A connected clip is converted to WAV and uploaded to Comfy.org storage first (Comfy.org login needed). A link goes straight to the library.
- **Group:** with a `group_id`, the asset joins that group. With an empty one, the node finds the AIGC group whose name is exactly `group_name`, or creates it. Use one group per person.
- **Real people:** verify the person in the ModelArk console, then paste the group ID. The node cannot start that QR-code flow.
- **Waiting:** with `wait_until_active` on, the node waits until the asset is Active. With it off, the asset is still Processing when the IDs come out.

## Outputs

<NodeOutputs id="BytePlusCreateAudioAsset" />

### Notes on outputs

- Connect `asset_id` to an `asset_N` slot of [Seedance 2.5 Reference to Video](../seedance-2-5-reference/). Refer to it in the prompt as `asset1`, `asset2` and so on, by slot.
- `asset_uri` is `asset://` plus the ID. `info` is the asset as JSON, with its status and type.
- The node also shows `asset_id` and `group_id` as text under the node. Save them to reuse the asset later.

## Limits and tips

- A connected clip must be 2 to 30 seconds long and, as WAV, at most 15 MB. For a longer or larger clip, trim it or pass a public MP3 in `audio_url`. A link is not checked for length or size here.
- `audio_url` must end in .wav or .mp3, or have no file extension.
- The node is not an output node. Connect at least one of its outputs to another node, or it does not run.
- The same connected clip, with the same group, project, account and `asset_name`, reuses its earlier asset while that asset still exists. This memory is cleared when ComfyUI restarts. A link in `audio_url` is never deduplicated.
- The node waits up to 10 minutes for Active, then stops with an error. The asset may still become Active: list it with [Asset Library](../asset-library/) before you create it again.
- Creating assets is rate limited by your rights tier: 3 requests per minute for Entry, 120 for Advanced and 300 for Premium.
- Creation requests are not retried automatically, so a timeout cannot create a second asset.
- Interrupting a run stops the node's wait. An asset that was already created stays in your library.

## Common errors

| Message | What to do |
|---|---|
| `[BytePlus] The asset library needs IAM AK/SK with asset-library permission …` | Add the IAM access key and secret key in **Settings → BytePlus**. The account also needs Advanced Creation Rights. |
| `[BytePlus] Asset audio must be 2 to 30 seconds long. Current: …s.` | Trim the clip to between 2 and 30 seconds. |
| `[BytePlus] Asset audio must be at most 15 MB (WAV). Current: … MB. …` | Trim the clip, or pass a public MP3 link in `audio_url`. |
| `[BytePlus] audio_url must link to a .wav or .mp3 file. Current: …` | Use a link that ends in .wav or .mp3. |
| `[BytePlus] Uploading the audio to Comfy.org storage failed: …` | Log in to Comfy.org in ComfyUI, or pass a public `audio_url`. |
