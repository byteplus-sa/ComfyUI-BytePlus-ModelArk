## What it does

Takes one image and separates it into a base image plus transparent layers: up to 99 on early-access 5.5, or 16 on 5.0 Pro/Flash. Each layer comes with its stacking order, bounding box, name and description, with optional rich-text OCR on 5.5.

The node bills for every run and does not save anything itself unless you turn on `save_layers`: connect **Save Image**, or send `layer_stack` to **Create Layered Image**, to keep the result.

## Inputs

<NodeInputs id="BytePlusSeedreamLayerSeparation" />

### Notes on inputs

- **Prompt:** an empty prompt separates all major elements. To target one area, add a tag such as `<bbox>left top right bottom</bbox>`. The coordinates run from 0 to 999 and are relative to the image.
- **Model:** 5.0 Pro offers `standard` and `fast` prompt optimization; 5.5 supports only `standard`. 5.0 Flash has no such setting. On 5.5, `seed` is a local rerun control, not a generation parameter.
- **crop_layers:** `full canvas` puts every layer on a canvas the size of the base image, ready for **ImageCompositeMasked**. `minimal size` crops each layer to its bounding box, which makes much smaller tensors. Rebuild the placement from the `bboxes` output with **Layers From Bounding Boxes**.
- **Saving files:** `save_layers` writes the base image and the original layer PNGs to the ComfyUI output folder under `filename_prefix`. `output_format` sets the format of the base image; layers are always PNG. It is the only setting in the pack that writes files by itself.
- **Layer count** (5.5): `max_images` includes the base image, with a range of 2-100 and default 30. Larger values permit finer decomposition; the model may return fewer images.
- **Text recognition** (5.5): enable `text_recognition` for rich-text OCR in `layers_json`. It may include recognized text, line boxes and style runs; non-text or irregular lettering may have no OCR result.

## Outputs

<NodeOutputs id="BytePlusSeedreamLayerSeparation" />

### Notes on outputs

- `layers` and `masks` list the layers from bottom to top and share the same order as `bboxes`.
- `masks` use the Load Image convention (1 means transparent). Add **InvertMask** before **ImageCompositeMasked**.
- `layer_stack` is always tight-cropped, whatever `crop_layers` says. Connect it to **Create Layered Image**, or extend it with **Add Layer**.
- `base_mask` is currently always fully opaque.
- `layers_json` lists the `z_index`, name, description and bounding box of each image, its background type and OCR when returned, and the saved file when `save_layers` is on. OCR retains the API's base-image coordinates, font matches, colors and text styles.

## Limits and tips

- Connect exactly one image. It needs at least 262,144 pixels in total (for example 512x512) and an aspect ratio between 1:16 and 16:1.
- Images above about 4 MP are scaled down before upload; on 5.5, inputs exceeding 36,000,000 pixels are rejected. Large layer counts can use substantial RAM: choose `minimal size` for `crop_layers`.
- `size` is `auto`, `1K`, `1.5K` or `2K`. `auto` follows the size of the input and stays between 1K and 2K.
- If you need a specific object on its own layer, name it in the prompt or mark its box. Seedream 5.5 reserves image-rate quota using `max_images` and returns unused quota; incomplete layer responses fail rather than silently dropping layers.
- Activate your model in the ModelArk console; 5.5 needs early-access entitlement. Background mode is not accepted for layer separation. For its optional `safety_identifier`, use a stable hashed ID of at most 64 ASCII characters, not personal data.
- If you interrupt the run, the node stops waiting. A request that was already sent may still be billed.
- A failed request that may have billed is never sent again automatically. See [Billing and cost](../../concepts/billing-and-cost/).
- For ordinary image generation use [Seedream](../seedream/).

## Common errors

| Message | What to do |
|---|---|
| `No BytePlus API key is set` | Add the key in **Settings → BytePlus**. See [API keys](../../get-started/api-keys/). |
| `Only a single input image is supported.` | Connect one image, not a batch of several. |
| `Image must have at least 262,144 pixels in total` | Scale the image up so it has at least 262,144 pixels, for example 512x512. |
| `must be between 1:16 and 16:1` | Crop the image so its aspect ratio falls inside the range. |
| `The model returned no layers` | Change the prompt or the input image and run again. |
