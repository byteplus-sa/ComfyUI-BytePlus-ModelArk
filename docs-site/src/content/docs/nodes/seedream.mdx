## What it does

Creates images with BytePlus Seedream from a text prompt, with reference-image editing on supported models. Pick the model first to see its inputs.

Seedream 5.5 adds early-access text-to-image and editing with up to 10 references, with automatic or explicit transparent PNG output.

The node bills for every image it generates and does not save anything itself: connect **Save Image** to keep the result.

## Inputs

<NodeInputs id="BytePlusSeedream" />

### Notes on inputs

- **Size:** `size_preset` lists ready-made sizes for 1:1, 3:4, 4:3, 16:9, 9:16, 2:3, 3:2 and 21:9. The entries ending in “(adaptive)” send only a resolution level and let the model choose the ratio. Choose **Custom** to use `width` and `height`. The size limits are under Limits and tips.
- **Reference images:** connect them to the `images` slots (`image_1`, `image_2`, …) in order. With reference images the model edits or combines them following the prompt. If a ten-reference graph loses a socket when reopened, combine references with **Batch Images** (`ImageBatch`) and connect the batch to one slot; the same total-image limit applies.
- **Related image sets** (5.0 Lite, 4.5 and 4.0): set `max_images` above 1 to let one request return between 1 and `max_images` related images, for example story scenes or character variations. Reference images plus `max_images` cannot exceed 15. With `fail_on_partial` on, the run aborts if any requested image is missing or returns an error.
- **Transparent background** (5.0 Pro and Flash): connect exactly one reference image, set `output_format` to `png`, set `background` to `transparent`, and connect the `MASK` of **Load Image** to `reference_mask`.
- **Transparent background** (5.5): the default `auto` follows the prompt; `transparent` always requests transparency and needs PNG, while `opaque` disables it. You can use zero to 10 references without input alpha. JPEG is supported with `auto` or `opaque` and is always opaque.
- **Several images in one run:** raise `generation_count`. The runs go in parallel. Models other than 5.5 send `seed` + N for generation N; on 5.5, `seed` is only a local rerun control, not a generation parameter.

## Outputs

<NodeOutputs id="BytePlusSeedream" />

### Notes on outputs

- With `generation_count` or `max_images` above 1, `IMAGE` holds all pictures as one batch. A picture of a different size is resized to the size of the first one.
- `mask` holds the result's transparency, with 1 meaning transparent, like **Load Image**. This includes transparent PNGs returned by 5.5 in `auto` mode; opaque output produces all zeros.
- To save a transparent PNG, connect `IMAGE` and `mask` to **Join Image with Alpha**, then connect its output to **Save Image**. Saving `IMAGE` alone discards transparency.
- `response` includes each image's actual `background`, size and format when returned by the API.

## Limits and tips

- Activate each Seedream model in the ModelArk console for the region you use. Seedream 5.0 Lite is not available in `eu-west-1`: the node stops before it sends anything. Seedream 5.5 needs early-access entitlement.
- The ratio must be between 1:16 and 16:1, and total pixels must fit the model: 921,600 to 4,624,220 on 5.5, 5.0 Pro and Flash; 3,686,400 to 16,777,216 on 5.0 Lite and 4.5; 921,600 to 16,777,216 on 4.0. Seedream 5.5 defaults to 2K adaptive and also offers 1K, 1.5K and custom sizes.
- Seedream 5.5 supports only `standard` prompt optimization and one image per request. Each reference side must exceed 14 pixels, with at most 36,000,000 total pixels. Use [Layer Separation](../seedream-layer-separation/) for layers and rich-text OCR. Its optional `safety_identifier` should be a stable hashed ID of at most 64 ASCII characters, not personal data.
- `thinking` is on by default where exposed (5.0 Flash and early-access 5.5 have no such setting). It can substantially increase generation time, most on 5.0 Pro, and it can only be switched off when no reference image is connected.
- For reference images of a character, a place or an object, the Production assets templates ([Character Sheet](../../templates/character-sheet/), [Location Sheet](../../templates/location-sheet/), [Prop Sheet](../../templates/prop-sheet/)) fill a fixed prompt from a few text boxes and send it to this node.
- Review generated lettering before publication, especially dense text and stylized headlines. If a result is rejected, review the prompt for policy compliance before submitting another billed request.
- If you interrupt the run, the node stops waiting. A request that was already sent may still be billed.
- A failed request that may have billed is never sent again automatically. See [Billing and cost](../../concepts/billing-and-cost/).

## Common errors

| Message | What to do |
|---|---|
| `No BytePlus API key is set` | Add the key in **Settings → BytePlus**. See [API keys](../../get-started/api-keys/). |
| `has not activated the model` | Open the ModelArk console and activate the model for the same region as your key. |
| `is not available in` | The model is not offered in your region, for example Seedream 5.0 Lite in `eu-west-1`. Pick another model, or another region in **Settings → BytePlus**. |
| `Generated image contains sensitive content` | Review the prompt and references for policy compliance before submitting another billed request. |
| `Rate Limit Exceeded (429)` | The node already waited and retried twice. Wait a moment, or lower `generation_count`. |
