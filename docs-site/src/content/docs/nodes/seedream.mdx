## What it does

Creates images with BytePlus Seedream from a text prompt. Connect up to 10 reference images (14 on Seedream 5.0 Lite) to edit a picture, combine several, or keep a subject consistent. Each model option shows its own inputs, so pick the model first.

The node bills for every image it generates. It does not save anything itself: connect **Save Image** to keep the result.

## Inputs

<NodeInputs id="BytePlusSeedream" />

### Notes on inputs

- **Size:** `size_preset` lists ready-made sizes for 1:1, 3:4, 4:3, 16:9, 9:16, 2:3, 3:2 and 21:9. The “adaptive” levels let the model choose the ratio. Choose **Custom** to use `width` and `height`, which accept ratios from 1:16 to 16:1.
- **Reference images:** connect them to the `images` slots in order. With reference images the model edits or combines them following the prompt.
- **Transparent background** (5.0 Pro and Flash): set `output_format` to `png`, set `background` to `transparent`, and connect the `MASK` of **Load Image** to `reference_mask`.
- **Several images in one run:** raise `generation_count`. The runs go in parallel and generation N uses `seed` + N, so the pictures differ.

## Outputs

<NodeOutputs id="BytePlusSeedream" />

### Notes on outputs

- With `generation_count` above 1, `IMAGE` holds all pictures as one batch.
- `mask` is empty unless `background` is `transparent`.

## Limits and tips

- Activate each Seedream model in the ModelArk console for the region you use. Seedream 5.0 Lite is not available in `eu-west-1`.
- Seedream 5.0 Pro with `thinking` on takes noticeably longer than the other models.
- A rejected result (“Generated image contains sensitive content”) can be a false alarm. Run again with another `seed` or reword the prompt.
- Parallel generations are not retried automatically: a failed request that may have billed is never sent twice.

## Common errors

| Message | What to do |
|---|---|
| `[BytePlus] No BytePlus API key is set. Add it in Settings > BytePlus …` | Add the key in **Settings → BytePlus**. See [API keys](../../get-started/api-keys/). |
| `has not activated the model` | Open the ModelArk console and activate the model for the same region as your key. |
| `Generated image contains sensitive content` | Run again with another seed or rephrase the prompt. |
| `RateLimitExceeded` | Wait a moment, or lower `generation_count`. |
