## What it does

Turns one image into a video with Seedance 1.0 on BytePlus ModelArk. The image becomes the first frame, and the prompt describes how the scene moves.

The node bills for every video it generates and waits until the task finishes. It does not save anything itself: connect **Save Video** to keep the result. Seedance 1.0 is the older family; for clips up to 30 seconds, use the newer [Seedance 2.5 First-Last-Frame to Video](../seedance-2-5-first-last-frame/), where the last frame is optional.

## Inputs

<NodeInputs id="BytePlusSeedanceImageToVideo" />

### Notes on inputs

- **Model:** `seedance-1-0-pro-fast-251015` (Pro Fast) is the default. `seedance-1-0-pro-250528` (Pro) is the other option.
- **Aspect ratio:** `adaptive` leaves the choice of ratio to the model. Pick a fixed ratio to force one.
- **Settings go in the widgets:** do not write flags such as `--resolution`, `--ratio`, `--dur`, `--frames`, `--seed`, `--camerafixed` or `--watermark` in the prompt. The node refuses a prompt that contains them.
- **Camera and price:** `camera_fixed` adds an instruction to keep the camera still; BytePlus does not guarantee the effect. `enable_offline_inference` uses the flex tier: it costs less, but the result can take up to 48 hours.
- **Several videos in one run:** raise `generation_count`. The runs go in parallel and generation N uses `seed` + N, so the videos differ.

## Outputs

<NodeOutputs id="BytePlusSeedanceImageToVideo" />

### Notes on outputs

- `VIDEO` is a list output. With `generation_count` above 1, the next node runs once per video.
- `last_frame` holds the final frame of every video as one image batch, in the same order. Feed it into the next Image to Video node to chain clips.
- With `non_blocking` on, the first run returns at once with the task IDs in `response` and no video, so nodes connected to `VIDEO` or `last_frame` are skipped. Run the node again to collect the finished video.

## Limits and tips

- The image must be 300 to 6000 pixels on each side, with a width to height ratio from 0.4 to 2.5. The node checks this before it sends anything.
- The image is sent inline as base64. A single image cannot exceed 30 MB in that form.
- Duration is 2 to 12 seconds. Resolution is 480p, 720p or 1080p.
- Activate each Seedance model in the ModelArk console for the region you use.
- The node keeps waiting until the task ends and shows its queued or running status under the node. With `enable_offline_inference` on, results can take up to 48 hours.
- Interrupting cancels tasks that are still queued. A task that is already running cannot be cancelled: it finishes and is billed. The node shows the task IDs, and [Video Query Tasks](../video-query-tasks/) finds them again. See [Interrupts and cancelling](../../concepts/interrupts/).
- A failed request that may have billed is never sent again automatically. With `generation_count` above 1, every video is billed. See [Billing and cost](../../concepts/billing-and-cost/).

## Common errors

| Message | What to do |
|---|---|
| `No BytePlus API key is set` | Add the key in **Settings → BytePlus**. See [API keys](../../get-started/api-keys/). |
| `image: width and height must be between 300 and 6000 pixels` | Resize the image so both sides are within the range. |
| `image: aspect ratio (width / height) must be between 0.4 and 2.5` | Crop or pad the image to a less extreme shape. |
| `has not activated the model` | Open the ModelArk console and activate the model for the same region as your key. |
| `Input image contains sensitive content` | Use another image. |
