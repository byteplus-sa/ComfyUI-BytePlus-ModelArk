## What it does

Finds places where the motion rhythm jumps (periodic stutter), generates in-between frames there, and removes consecutive identical frames. The picture size stays the same, which suits Seedance videos with occasional stutter, low frame rate clips and screen recordings. Connect a local `video` or set a public `video_url`; it needs the separate AI MediaKit API key (Singapore only, see [API keys](../../get-started/api-keys/)). A run that repairs something bills, and nothing is saved: connect **Save Video** to keep the result.

## Inputs

<NodeInputs id="BytePlusVideoSmoothness" />

### Notes on inputs

- **Source:** use `video` or `video_url`, not both. A connected video is uploaded to Comfy.org storage first (Comfy.org login needed). A link is sent as it is.
- **Stutter repair:** with `periodic_stutter` on `repair`, `align_source_fps` and `insert_frame_indices` appear. `insert_frame_indices` takes distinct zero-based frame numbers, comma-separated, for stutter points the detector misses.
- **Detect only:** set a repair to `detect only` to count problems without changing the video. The duplicate step runs after the stutter repair, on its result.
- **Checks before upload:** a connected video must be at most 4096x2160. While any repair is on it must also be at most 35 seconds long. With both set to `detect only` there is no length limit.

## Outputs

<NodeOutputs id="BytePlusVideoSmoothness" />

### Notes on outputs

- If MediaKit returns no repaired video, `VIDEO` is your source passed through. That happens with both steps on `detect only`, when nothing needed fixing, or when MediaKit's quality check skipped the repair. The task is then billed as detection only.
- In that case there is no comparison, and nodes using `comparison` are skipped.
- `inserted_frame_count` is what the detector found. The repair may still have been skipped, so do not read it as frames added.

## Limits and tips

- The comparison puts the source on the left and the repaired video on the right, in sync on the repaired clip's timeline. Each half has a short side of at most 1080 px.
- If building the comparison fails, the repaired video is still returned and the failure is logged.
- `align_source_fps` keeps the source frame rate, frame count and duration by removing a low-motion frame for each inserted one. Off gives the best repair, but the frame rate may rise.
- `insert_frame_indices` frames are always inserted, even when MediaKit's quality check skips the automatic repair.
- Every run sends a new task. Interrupting stops the wait for the result.
- MediaKit result links expire after 24 hours, so the node downloads the result right away. Only the Singapore region is available.

## Common errors

| Message | What to do |
|---|---|
| `No AI MediaKit API key is set` | Add the AI MediaKit key in **Settings → BytePlus**. See [API keys](../../get-started/api-keys/). |
| `Video Smoothness repairs videos up to 35s` | Trim the clip, or set both repairs to `detect only` to analyse a longer video. |
| `Video resolution must be at most 4096x2160 (4K)` | Scale the video down before repairing it. |
| `insert_frame_indices takes distinct zero-based frame numbers` | Write numbers such as `80, 120`, with no repeats and none below 0. |
| `Uploading the video to Comfy.org storage failed` | Log in to Comfy.org in ComfyUI, or set `video_url` to a public link. |
