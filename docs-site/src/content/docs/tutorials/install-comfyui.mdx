**Module 1. Your goal:** Open ComfyUI with the BytePlus nodes ready to use. You do not need to download local image or video models for this course; Seedream 5.5 and Dreamina Seedance 2.5 run through BytePlus ModelArk.

## Before you start

- Use a computer supported by ComfyUI, with internet access and permission to install applications.
- Choose a folder for your course reference images, workflows and results.
- If ComfyUI is already installed, go straight to installing the BytePlus pack below.

ComfyUI must still meet its own installation requirements, even though generation happens in the cloud.

## Install and launch ComfyUI

<Steps>

1. Choose the official guide for your computer: [Windows Desktop](https://docs.comfy.org/installation/desktop/windows), [macOS Desktop](https://docs.comfy.org/installation/desktop/macos) or [Linux Desktop](https://docs.comfy.org/installation/desktop/linux). Check the guide's hardware requirements before downloading.
2. Download the installer from the [official ComfyUI download page](https://comfy.org/download). Install the application and follow its initial setup, including choosing the folder for ComfyUI's files.
3. Let setup finish, then launch ComfyUI. You should see the canvas where nodes are connected.

</Steps>

For a computer or environment that needs another installation method, follow the [official manual installation guide](https://docs.comfy.org/installation/manual_install). A default manual server opens at `http://127.0.0.1:8188`; Desktop presents the interface in its application.

## Install the BytePlus pack

Use **Nodes Manager** as your first choice: **top-left dropdown > Extensions > Nodes Manager > search `byteplus` > Install**. Click the ComfyUI logo beside the small down arrow to open the dropdown, then choose **Extensions**.

<Shot src="guides/nodes-manager-menu.webp" alt="ComfyUI top-left dropdown with Extensions visible" caption="Open the dropdown beside the ComfyUI logo, then choose Extensions." />

In older layouts with a **Manager** button, open **ComfyUI-Manager > Custom Nodes Manager** instead.

<Shot src="guides/nodes-manager-byteplus.webp" alt="Nodes Manager with byteplus search results and byteplus-sa publisher labels" caption="Search byteplus and choose the ModelArk package from byteplus-sa." />

<Steps>

1. In **Nodes Manager**, keep **Node Pack** selected and search for **byteplus**. Choose **ComfyUI BytePlus ModelArk, Speech, OmniHuman & MediaKit** from **byteplus-sa** (package ID: `ComfyUI-BytePlus-ModelArk`).
2. Press **Install** and wait for the package and its requirements to finish installing. If it is already installed, open the card and use **Update** when a newer release is available.
3. Click **Apply Changes** if prompted, or restart ComfyUI. In Desktop, close and reopen the application. For a manual server, stop and restart the server process, then reload the browser tab. Reloading a tab alone does not load a newly installed Python node pack.

</Steps>

The OmniHuman nodes use this same installation. For the separate **BytePlus Avatar Studio** app, install its package from **byteplus-sa** in the same results as well; Studio is not needed for this course.

Use the **Comfy CLI** as your second option and a **release ZIP** only as a last resort. The [pack installation guide](../../get-started/install/) covers both alternatives and the **Install path already exists** error. If an update reports that no release is available for the selected option, follow the [update guide](../../get-started/update/) instead of assuming the pack is current.

## Update before later lessons

When a lesson asks you to update the pack, return to **top-left dropdown > Extensions > Nodes Manager > search `byteplus`**. Open the **ComfyUI-BytePlus-ModelArk** card from **byteplus-sa** and choose **Update** when a newer release is available. Wait for completion, then **Apply Changes** if prompted or restart ComfyUI and reload the editor. Do not install another copy.

<Shot src="guides/nodes-manager-update.webp" alt="BytePlus ModelArk selected in Nodes Manager with the Update button and update-options dropdown visible" caption="An installed pack has Update in its details panel; the adjacent dropdown shows update options." />

If no release is available for the selected option, check the [update guide](../../get-started/update/). If Manager shows **Install** but reports that the folder already exists, use the [installation recovery steps](../../get-started/install/#if-the-install-path-already-exists). Keep your workflows and `user/.env` credentials.

## Find your course tools

Open **Nodes** in the left sidebar and search for **BytePlus Seedream**. Look under **BytePlus ModelArk** for the generation node, not **Layer Separation**. Its title may include model-version numbers.

The **Seedream** and **Image to Draft to 1080p** templates are included when you install the pack. Open **Templates** in the left sidebar, look under **ComfyUI-BytePlus-ModelArk**, and open **Seedream**. For a manual installation, the group may use your installation folder's name. Do not choose a core ByteDance partner template; those use a different account connection.

<TemplateFacts file="Seedream.json" showDownload={false} />

The included Seedream template still defaults to **Pro**. The course uses `seedream 5.5` instead. If that option is missing, update the BytePlus pack through Nodes Manager and restart ComfyUI. In Module 2, you will override the model, reference and prompt before running.

Open **Settings** and search for **BytePlus**. Find **Default credentials** and its **ModelArk API key** row. Leave it empty for now; you configure it in Module 2.

<Shot src="tutorials/settings-entry.webp" alt="Settings searched for BytePlus, showing the ModelArk API key field, matching region selector and Save button" caption="Find the ModelArk row; other service credentials are not needed for this course." />

## Practice

Find the Seedream node, open the Seedream template, and locate the ModelArk key row. Do not run generation yet.

## Completion check

- ComfyUI opens and shows its canvas.
- You can find BytePlus Seedream in node search.
- The course's Seedream template opens with BytePlus nodes.
- Settings includes the ModelArk API key row.
- You can reopen Nodes Manager and find the installed BytePlus pack's Update control.
